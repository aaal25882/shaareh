# شارح — شرح و تفسیر شعر و ادب فارسی

گزیده‌ی اشعار و کتاب‌های ادب فارسی با شرحِ ویدیویی. کنارِ هر ویدیو فهرستِ ابیات از **سمت راست** باز می‌شود و
کلیک روی هر بیت، ویدیو را به همان بخشی می‌برد که آن بیت روی تصویر آمده و شرحش آغاز شده است.
سایت سه‌زبانه است (فارسی، انگلیسی، عربی) و **بدون بک‌اند** روی GitHub Pages اجرا می‌شود.

تاریخچه‌ی تغییرات: [docs/WHATS-NEW.md](docs/WHATS-NEW.md) (خودمانی) و [docs/WHATS-NEW-TECH.md](docs/WHATS-NEW-TECH.md) (فنی).

## اجرای محلی

```bash
npm start
```

سپس `http://localhost:8080` را باز کنید. هیچ وابستگی‌ای لازم نیست (Node 18 به بالا).
روی localhost ویدیوهای آپارات از راهِ `server.js` در پلیرِ کاملِ شارح پخش می‌شوند.

## انتشار روی GitHub Pages

هر push به شاخه‌ی `main`، پوشه‌ی `public/` را با گردش‌کارِ `.github/workflows/pages.yml` منتشر می‌کند.

## صفحه‌ها

| صفحه | کار |
| --- | --- |
| `index.html` | اسلایدر، «فالِ شارح»، فهرستِ شرح‌ها با فیلتر و جست‌وجو |
| `watch.html?id=…` | پلیر و پنلِ ابیات · `&v=3` از بیتِ سوم · `&t=1:23` از زمانِ مشخص · `?aparat=<لینک>` هر ویدیوی آپارات |
| `about.html` | دربارهٔ ما و تماس با ما |
| `studio.html` | زمان‌بندیِ ابیات (ابزارِ مدیر سایت؛ در پانویس پیوند دارد) |

## آپارات: با سرور یا بی سرور

| | بدونِ سرور (پیش‌فرض) | با پراکسی |
| --- | --- | --- |
| کلیک روی بیت ← همان لحظه‌ی ویدیو | ✓ (پلیرِ آپارات با `startTime`) | ✓ |
| روشن شدنِ زنده‌ی بیتِ در حالِ شرح | فقط بیتِ کلیک‌شده | ✓ |
| انتخابِ کیفیت و سرعت، نشانه‌ی ابیات روی خطِ زمان | — | ✓ |
| پخشِ خودکار پس از کلیک روی بیت | به مرورگر بستگی دارد | ✓ |

API آپارات اجازه‌ی درخواستِ مستقیم از مرورگر (CORS) نمی‌دهد؛ برای پلیرِ کامل یک پراکسیِ کوچک لازم است که فقط
اطلاعاتِ ویدیو را می‌گیرد — خودِ ویدیو مستقیم از سرورهای آپارات پخش می‌شود و ترافیکِ سنگینی به پراکسی نمی‌رسد.

- **روی سرورِ خودتان:** `HOST=0.0.0.0 ALLOW_ORIGIN=https://<نام>.github.io node server.js`
- **روی Cloudflare Workers:** فایلِ `proxy/cloudflare-worker.js` با متغیرِ `ALLOW_ORIGIN`

سپس نشانیِ پراکسی (مثلاً `https://example.com/api/aparat/`) را در `SITE.aparatProxy` در `public/js/data.js` بگذارید.

## افزودنِ شرح

1. **استودیو:** لینکِ آپارات را بدهید، متنِ شعر را از گنجور بگیرید، زمانِ ابیات را با کلیدِ T ثبت کنید (در حالتِ امبد، زمان‌ها را دستی بنویسید یا فایلِ همان ویدیو را برای زمان‌گذاری باز کنید) و JSON خروجی را به `public/data/episodes.json` اضافه کنید.
2. **وارد کردنِ یک کانال:** `node tools/aparat-import.mjs <کانال> --limit 20` (پیش‌نمایش) و سپس با `--write`. ابیات از توضیحاتِ ویدیوها خوانده می‌شوند؛ زمان‌ها را بعداً در استودیو ثبت کنید.

ساختارِ هر شرح (فیلدهای متنی می‌توانند رشته یا `{"fa": …, "en": …, "ar": …}` باشند):

```json
{
  "id": "hafez-252-1",
  "title": { "fa": "…", "en": "…", "ar": "…" },
  "poet": "hafez",
  "book": "دیوان حافظ",
  "poem": "غزل شمارهٔ ۲۵۲",
  "presenter": "…",
  "summary": "…",
  "image": "pics/hafez2.jpg",
  "ganjoor": "https://ganjoor.net/hafez/ghazal/sh252",
  "timing": "draft",
  "source": { "type": "aparat", "hash": "a20ofi6", "duration": 2705 },
  "verses": [
    { "t": 741, "m1": "مصراع اول", "m2": "مصراع دوم", "note": { "fa": "…", "en": "…" } },
    { "t": null, "text": "بیتِ بی‌زمان: دیده می‌شود ولی قابل کلیک نیست" }
  ]
}
```

ابیات به ترتیبِ شعر می‌آیند و زمان‌ها لازم نیست صعودی باشند. `source.type` می‌تواند `aparat` یا `file` (با `url`) باشد.

## زبان‌ها

متن‌های رابط در `public/lang/<کد>.json`. برای زبانِ تازه، فایلش را بسازید و یک ردیف به `LANGS` در `public/js/i18n.js` و به آرایه‌ی `L` در اسکریپتِ کوچکِ `<head>` هر صفحه اضافه کنید.

## لوگو و تصاویر

فایل‌های منبع در `brand/`: `shaareh-logo.ai` (Illustrator) و `og-image.psd` (Photoshop)، به‌همراهِ اسکریپت‌هایی که آن‌ها را ساخته‌اند و با *File › Scripts* دوباره اجرا می‌شوند. لوگو برداری‌شده‌ی لوگوی shaareh.ir است.
